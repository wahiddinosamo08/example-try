
# Wahid Streamlit Calculator

A simple calculator application built with [Streamlit](https://streamlit.io/).

## Features

- Basic arithmetic operations (addition, subtraction, multiplication, division)
- Clean and intuitive user interface
- Real-time calculation results

## Installation

```bash
pip install streamlit
```

## Usage

```bash
streamlit run app.py
```

## Project Structure

```
wahid-streamlit/
├── app.py
├── README.md
└── requirements.txt
```

## Requirements

- Python 3.8+
- Streamlit
